Movie API

A small REST API over the real MovieLens dataset (9,742 movies, 100,836 ratings), backed by Redis. Built as the demo app for a Docker containerization & orchestration comparison.

Every response includes served_by or a host field with the container's hostname — useful when this app is running scaled to several replicas (Compose 3x or Swarm), to see requests being spread across different backend containers.

Endpoints

GET/health

Liveness/readiness check. Returns 200 if the app can reach Redis, 503 otherwise. Used by container health checks and by the orchestrator to know when a replica is ready to receive traffic.

curl http://localhost:8000/health

{"status": "ok", "host": "a1b2c3d4e5f6"}
GET/stats

Basic dataset stats — how many movies are loaded.

curl http://localhost:8000/stats

{"movies_loaded": 9742, "host": "a1b2c3d4e5f6"}
GET/movies/search

Case-insensitive substring search over movie titles.

Query paramTypeDefaultNotes
qstringrequiredsubstring to match against the title
limitint20capped at 100
curl "http://localhost:8000/movies/search?q=toy&limit=5"

{
  "results": [
    {"movie_id": "1", "title": "Toy Story (1995)"},
    {"movie_id": "3114", "title": "Toy Story 2 (1999)"},
    {"movie_id": "78499", "title": "Toy Story 3 (2010)"}
  ],
  "count": 3
}
GET/movies/<movie_id>

Fetch a single movie's metadata and running average rating.

curl http://localhost:8000/movies/1

{
  "movie_id": "1",
  "title": "Toy Story (1995)",
  "genres": ["Adventure", "Animation", "Children", "Comedy", "Fantasy"],
  "avg_rating": 3.92,
  "num_ratings": 215,
  "served_by": "a1b2c3d4e5f6"
}

404 if the movie id doesn't exist.

POST/movies/<movie_id>/rate

Submit a new rating. The stored average is updated with a read-modify-write (an atomic Redis Lua script), and the new count/average are returned.

Body fieldTypeConstraint
ratingfloat0.5 – 5.0
curl -X POST http://localhost:8000/movies/1/rate \
  -H "Content-Type: application/json" \
  -d '{"rating": 4.5}'

{"movie_id": "1", "num_ratings": 216, "avg_rating": 3.9227}

400 if rating is missing or out of range · 404 if the movie id doesn't exist.

Trying it end to end

# 1. find a movie
curl "http://localhost:8000/movies/search?q=matrix"

# 2. look at it
curl http://localhost:8000/movies/2571

# 3. rate it
curl -X POST http://localhost:8000/movies/2571/rate \
  -H "Content-Type: application/json" -d '{"rating": 5}'

# 4. confirm the average moved
curl http://localhost:8000/movies/2571
Data: MovieLens "latest-small" (GroupLens Research) · Storage: Redis · Served by Flask/Gunicorn in a container.
